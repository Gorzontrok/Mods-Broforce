# Filtered Bros

Choose which bros can spawn in the game. Want to play with only melee bros? You can! If you haven't unlocked a bro, their name will be hidden and you won't be able to uncheck them. If you uncheck all bros, the mod will use the game's default spawn list.

You can also toggle Expendabros and unused bros.
