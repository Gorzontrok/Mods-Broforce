# Expendables Bros In Game

Play as the Expendabros in Broforce, including Brondfly (a hidden bro). This mod also includes fixes for the Expendabros. This mod is a standalone part of Tweaks From Pigs!

You can spawn with one of the Expendabros or rescue them.

## Installation Instructions

Detailed installation instructions can be found [here](https://steamcommunity.com/sharedfiles/filedetails/?id=2434812447).
